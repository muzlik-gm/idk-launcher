# Product

## Register

product

## Users

Minecraft players and modders who want a fast, customizable launcher that feels like an extension of the game itself. They open the launcher to pick a modpack or version, tweak settings, check on friends, and launch. They expect it to feel like part of Minecraft — not a generic tool bolted onto it.

## Product Purpose

IDK Launcher is an Electron-based Minecraft client manager. It handles authentication (Ely.by, Microsoft), modpack management, version selection, mod installation, friend lists, in-game overlays, and launch. Success is a launcher that disappears — the player picks their setup and plays, with no friction, no confusion, and no visual noise getting in the way.

## Brand Personality

Clean, fast, gamer. Playful, friendly. Powerful, customizable. Minecraft-authentic. The personality is a tension between precision and warmth — it should feel engineered but not cold, playful but not childish. The Minecraft DNA is real: blocky motifs, green accent heritage, mojang typeface, but elevated beyond default textures into something that feels premium and intentional.

## Anti-references

- SaaS blandness: cream backgrounds, rounded cards, bland gradients, generic "AI default" aesthetics
- Over-complicated/cluttered: too many visual elements fighting for attention, nested cards, excessive borders
- Generic Minecraft launcher: looks like every other MC tool, no identity, default textures plastered on

## Design Principles

1. **Minecraft DNA, elevated.** Blocky motifs, green accent heritage, mojang typeface — but refined into a premium, intentional system. Not a texture pack on a UI.
2. **Engineered warmth.** Precision layout, tight spacing, performance-aware rendering — but with personality, playfulness, and human warmth in the details.
3. **Disappearing interface.** The launcher should vanish when the player is in flow. No visual noise, no unnecessary chrome, no friction between intent and action.
4. **Customization as identity.** Theming, modpacks, settings — the launcher adapts to the player, not the other way around. Every surface should feel personal.
5. **Performance is a feature.** 60fps interactions, instant responses, no jank. The launcher should feel as fast as the game it launches.

## Accessibility & Inclusion

WCAG AAA. Contrast ratios ≥7:1 for body text, ≥4.5:1 for large text. Full keyboard navigation with visible focus indicators. Screen reader support with ARIA labels. Reduced motion support via `prefers-reduced-motion`. Color is never the sole indicator of state.
